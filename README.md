# 32 Podcast

Официалният сайт на 32. Подкаст — достъпен на [32-podcast.github.io/www](https://32-podcast.github.io/www/).

## Технологии

- Чист HTML + CSS (без框架, без build tools)
- [Kometa](https://ifonts.xyz/kometa-font.html) от Kiril Zlatkov & Vassil Kateliev – основният шрифт
- Font Awesome 6 за икони
- Хостинг на GitHub Pages

## Страници

- `index.html` – Начало
- `episodes.html` – Епизоди
- `guests.html` – Гости
- `rubrics.html` – Рубрики
- `schedule.html` – Програма
- `team.html` – Екип
- `contact.html` – Контакти
- `whats-new.html` – Какво ново
- `404.html` – Грешка

## Дизайн

Дизайнът е вдъхновен от [Zen Browser](https://zen-browser.app) – хартиен фон (`#f2f0e3`), коралов акцент (`#f76f53`), тъмна тема, декоративни елементи с CSS анимации.
